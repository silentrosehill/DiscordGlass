# User delivery preferences

Do not use subagents. The user wants the same `~/Desktop/DiscordGlass Patch.app` refreshed after every update. Finish rebuilding the overlay and any changed Vencord plugin bundle, then run `build-patch.sh` to refresh that Desktop app and its payload. Preserve Discord settings and backups. Never restart Discord or disconnect a call without an explicit user action/approval; the patch app asks before any restart. Prefer overlay-only updates whenever the plugin build already matches.
